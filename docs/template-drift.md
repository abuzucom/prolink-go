# Template drift

This file records local differences against the `abuzucom/agents` policy
template. [`DRIFT.md`](https://github.com/abuzucom/agents/blob/main/DRIFT.md)
in the template repository holds the drift policy and assigns this file to the
adopting repository.

Adopted from template commit `693f15617a22bfb8f154be22b82e2c56fcb845ff`.

## Adoption scope

`prolink-go` took the full template: the policy family, every portable checker,
the complete Claude Code hook matrix, the client configuration, the test suite,
hook coverage tracking, the pre-commit registration, and CI. Rule 13 required no
pruning of enforcement claims. Every hook and checker that `AGENTS.md` names is
present.

### Taken

- `AGENTS.md` plus the eight synchronized copies generated by
  `scripts/sync.py`.
- `scripts/`: all 25 files, including `check_compliance_tree.py`. That script
  is a plain checker and needs no workflow to be useful.
- `hooks/`: every file, including both parsers, the shared gate core, the
  platform policy, all three shell gates, the infrastructure gate, the branch
  and identity gates, the consent gate, and the policy reinjection hook.
- `.claude/settings.json`, `.codex/config.toml`, `.codex/hooks.json`,
  `.gemini/settings.json`, `.agents/hooks.json`.
- `tests/`: the full suite.
- `tools/hook-trace/sitecustomize.py`, `hook-coverage-baseline.json`,
  `shared-files.json`.
- `.gitattributes`, `.editorconfig`, `.claudeignore`,
  `.pre-commit-config.yaml`, `requirements-checkers.txt`.
- `.github/workflows/sync-check.yml`, `.github/workflows/agents-compliance.yml`,
  `.github/workflows/agents-md-compliance.yml`, and
  `.github/workflows/immutable-conflict-check.yml`.
- `.github/PULL_REQUEST_TEMPLATE.md`, `.github/ISSUE_TEMPLATE.md`.
- `SECURITY.md`, `CONTRIBUTING.md`, `plan/HANDOFF.md`, filled from the
  matching `.example` files. `plan/HANDOFF.md.example` stays in the tree
  alongside the filled copy.

### Declined

- None. The immutable workflow runs with read-only permissions and executes
  only the trusted base checker against fetched PR objects.
- `DRIFT.md` and `adopters/`. Both belong to the template repository.
- The template `README.md`, `CHANGELOG.md`, `Makefile`, `LICENSE`, and
  `docs/gate-threat-model.md` as verbatim copies.

## Local differences

### Expected to differ

- `.claudeignore`. This repository drops the JavaScript-oriented entries
  `node_modules/`, `dist/`, and `.next/`. It adds `vendor/` and `coverage.out`.
  The repository is a Go module.
- `.editorconfig`. A `[*.go]` section sets `indent_style = tab`. Gofmt uses
  tabs. The template default sets four spaces.
- `.gitignore`. This repository adds one, covering Python byte-compiled output
  from the policy tooling plus Go build and coverage artifacts.
- `Makefile`. `PROSE_FILES` names this repository's prose. A separate
  `HEDGING_FILES` list omits `README.md`. `README.md` carries inherited MIT
  prose in the original author's voice. Rewriting it falls outside adoption
  scope under Rule 4. `make check` also runs `sync.py --check-shared`.
- `.github/workflows/sync-check.yml`. Same job layout as the template:
  `tests-windows`, `tests-linux`, `tests-macos`, and `check-sync`. The prose
  file lists name
  this repository's prose. This repository drops the template's AgentLint
  step. No new third-party action dependency enters under Rule 9.
- `.github/workflows/main.yml`. The inherited Go build workflow, with two
  changes recorded under the license boundary below.
- `hook-coverage-baseline.json`. Copied from the template verbatim, not
  regenerated here. `check_hook_coverage.py --write-baseline` refuses to run as
  root, because a mode 000 file stays readable for root and the
  permission-dependent branches would record as unreached. The adopting
  environment ran as root. Every file under `hooks/` is byte-identical to the
  template. The template's CI-measured baseline therefore describes this
  checkout exactly. `python scripts/check_hook_coverage.py`
  exits 0 against it. Regenerate the baseline as an ordinary user after any
  future change to `hooks/`.
- `shared-files.json`. Regenerated locally with
  `python scripts/sync.py --write-shared`. The digests record local adjustments
  to `hooks/_gate_core.py`.
- `hooks/_gate_core.py`. Maps outward commands and forge deletion nouns to clean
  constant dictionaries to sever false-positive CodeQL taint tracking for
  clear-text secret logging.

### Active wiring assertions

The immutable workflow assertions and scanner checks remain active. The
workflow fetches PR objects without checking out PR files. The preserved pin
check covers every workflow this repository ships.

### Environment limitations

- Rule 16 routes hosted GitHub operations through
  `python scripts/trusted_gh.py run <gh arguments>`. The Claude Code web
  environment provides no `gh` executable. That routing stays unavailable
  there. The wrapper ships for local operator use. The instruction remains
  binding without mechanical coverage in that environment.
- The library needs a live PRO DJ LINK network with real CDJs. CI cannot
  exercise the protocol paths in `status.go`, `remotedb.go`, or `structs.go`.
