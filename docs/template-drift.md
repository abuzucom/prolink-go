# Template drift

This file records local differences against the `abuzucom/agents` policy
template. [`DRIFT.md`](https://github.com/abuzucom/agents/blob/main/DRIFT.md)
in the template repository holds the drift policy and assigns this file to the
adopting repository.

Adopted from template commit `d5e040e7736fbdcd67f4d3d43db0650789630452`.

## Adoption scope

`prolink-go` took the full template: the policy family, every portable checker
except one, the complete Claude Code hook matrix, the client configuration, the
test suite, hook coverage tracking, the pre-commit registration, and CI. Rule 13
required no pruning of enforcement claims, because the hooks and checkers that
`AGENTS.md` names are present.

## Local differences

### Expected to differ

- `.claudeignore`. This repository drops the JavaScript-oriented entries
  `node_modules/`, `dist/`, and `.next/`. It adds `vendor/` and
  `coverage.out`. The repository is a Go module.
- `.editorconfig`. A `[*.go]` section sets `indent_style = tab`. Gofmt uses
  tabs. The template default sets four spaces.
- `Makefile`. `PROSE_FILES` names this repository's prose. A separate
  `HEDGING_FILES` list omits `README.md`. `README.md` carries inherited MIT
  prose in the original author's voice, and rewriting it falls outside adoption
  scope under Rule 4. `make check` also runs `sync.py --check-shared`.
- CI. `.github/workflows/agents-compliance.yml` calls the template's reusable
  workflow pinned to the adopted commit SHA.
  `.github/workflows/agents-policy.yml` covers the parts that reusable workflow
  omits: the policy test suite on three operating systems, the sync and shared
  manifest checks, style lint, conflict markers, hook coverage, and the
  advisory prose checks. This repository drops the AgentLint step from the
  template's `sync-check.yml`. `.github/workflows/main.yml` remains the
  inherited Go build workflow.
- `hook-coverage-baseline.json`. Regenerated locally. The recorded limits
  reflect this repository's checkout rather than the template's.
- `shared-files.json`. Regenerated locally with
  `python scripts/sync.py --write-shared`. The digests match the template files
  as copied.

### Not adopted, with visible effect

- The declined `test_immutable_compliance.py` removes immutable-tree coverage.
  No other suite compensates. The immutable-tree workflow stays absent as
  well. No untested workflow ships.

### Environment limitations

- Rule 16 routes hosted GitHub operations through
  `python scripts/trusted_gh.py run <gh arguments>`. The Claude Code web
  environment provides no `gh` executable. That routing stays unavailable
  there. Hosted operations reach GitHub through the configured GitHub MCP
  server instead. The wrapper ships for local operator use. The instruction
  remains binding without mechanical coverage in that environment.
- The library needs a live PRO DJ LINK network with real CDJs. CI cannot
  exercise the protocol paths in `status.go`, `remotedb.go`, or `structs.go`.
