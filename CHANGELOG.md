# Changelog

All notable changes to this project appear in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Versioning follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
Public API stability starts at `1.0.0`.

## [Unreleased]

### Added

- `AGENTS.md` as the canonical agent policy, adopted from `abuzucom/agents` at
  commit `d5e040e7736fbdcd67f4d3d43db0650789630452`.
- Eight synchronized policy copies generated by `scripts/sync.py`: `CLAUDE.md`,
  `GEMINI.md`, `CONVENTIONS.md`, `.cursorrules`, `.clinerules`,
  `.windsurfrules`, `.copilot-instructions`, and
  `.github/copilot-instructions.md`.
- Portable policy checkers under `scripts/`, covering branch names, git
  identity, banned agents, secrets, weak hashing, checkout credentials,
  container root, conflict markers, ASCII and dash style, spelling, language,
  and prose.
- Claude Code command and lifecycle gates under `hooks/`, wired through
  `.claude/settings.json`, with client configuration for Codex, Gemini, and
  Antigravity.
- Policy test suite under `tests/`, run by `scripts/run_tests.py`.
- Hook coverage tracking through `scripts/check_hook_coverage.py`,
  `tools/hook-trace/sitecustomize.py`, and `hook-coverage-baseline.json`.
- CI workflows `sync-check.yml`, `agents-compliance.yml`, and
  `agents-md-compliance.yml`, adopted from the template.
- `Makefile`, `.pre-commit-config.yaml`, and `requirements-checkers.txt` for
  local policy checks.
- `SECURITY.md`, `CONTRIBUTING.md`, `plan/HANDOFF.md`,
  `docs/template-drift.md`, `.github/PULL_REQUEST_TEMPLATE.md`, and
  `.github/ISSUE_TEMPLATE.md`.
- `LICENSE.BSD-3-Clause` covering every file added after the initial fork.

### Changed

- `README.md` gained a License section describing the split license.
- Compliance workflows run on pull requests and use trusted immutable scans.
- Trusted immutable scans fetch PR objects without checking out PR files.
- Checker dependency installation enforces PyYAML artifact hashes.
- The policy test suite runs on Linux, macOS, and Windows.
- `.claudeignore` and `.editorconfig` adapted to Go paths and gofmt tabs.

### Fixed

- Hardened PRO DJ LINK input handling against spoofed announcements, malformed
  remote database packets, oversized fields, device state races, and unbounded
  status callback goroutines.

- `.github/workflows/main.yml` sets `persist-credentials: false` on the
  `actions/checkout` step. The default left the ephemeral `GITHUB_TOKEN` in the
  runner git configuration for the rest of the job.
- `.github/workflows/main.yml` pins `actions/checkout`, `actions/setup-go`, and
  `golangci/golangci-lint-action` to full commit SHAs. Rule 9 forbids a tag or
  moving branch reference. Each pin names the commit its tag already pointed
  at. The workflow keeps its behavior.

## [1.0.0] (2026-07-14)

The inherited fork state at commit `2a2e0ef`. Original work by Evan Purkhiser
under the MIT license.

### Added

- `Network` client for the Pioneer PRO DJ LINK protocol, with `Connect` and
  `AutoConfigure` plus virtual CDJ announcement.
- `DeviceManager` for device discovery, active device queries, and add and
  remove listeners.
- `CDJStatusMonitor` and `CDJStatus` for player status decoding.
- `RemoteDB` for Rekordbox track metadata and album artwork queries.
- `bpm.ToDuration` for beat length calculation from BPM and pitch.
- `mixstatus.Processor` for now-playing semantics across a DJ setup.
- `cmd/status-reciever` sample binary.
